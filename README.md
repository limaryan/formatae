# IMGConvert
Conversor de imagens estático para GitHub Pages. Converte WEBP, PNG, JPG/JPEG e BMP para PNG, JPG ou WEBP diretamente no navegador.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `app.js` para a raiz.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)` e salve.

Não requer servidor, banco de dados ou API.
