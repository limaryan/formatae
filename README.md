# Formataê V3

**Fácil. Rápido. Gratuito.**

Site estático para GitHub Pages em `formatae.com.br`.

## Recursos
- Conversão local WEBP / PNG / JPG / BMP para PNG / JPG / WEBP
- Conversão em lote
- Qualidade configurável
- Redimensionamento com preservação de proporção
- Páginas Sobre, Privacidade, Termos, Cookies e Contato
- `robots.txt`, `sitemap.xml` e favicon
- Espaços reservados para publicidade futura (nenhum anúncio ativo)

## Publicação
Envie o conteúdo desta pasta para a raiz do repositório usado no GitHub Pages. Antes de ativar publicidade, analytics ou cookies de terceiros, revise as páginas de Privacidade e Cookies conforme os serviços realmente adotados.
